# 工业工件抓取实证数据

当前实证研究统一使用 8 件工件、72 个场景。场景清单见 `active_dataset_72.json`，论文、点云评价及三个物理仿真实验环境均以这份清单为准。

## 当前数据

数据集包含轴套／隔套和安装块两类工业形状，每类 4 个尺寸变体，共 8 件工件。每件 3 个固定平面位置／偏航角，每个位姿配单件、邻近工件、料框壁三种条件，共 `8 × 3 × 3 = 72` 个场景，每种条件各 24 个。模型使用冻结权重，这批场景统一用于实验评价，不设训练、开发或测试子集。

这是工业形状的合成预实验集，模型没有加工螺纹、倒角和制造公差，不是厂家标准件 CAD 或现场实拍。尺寸、网格和来源逐件登记；不把香蕉、词典等生活物品纳入工业主数据。

每场景只读取固定左右图像及标定，共 144 张输入 RGB，双目基线为 60 mm。资产中的辅助视角不参与本次计算。图像由华硕 pyrender/EGL 环境按透视相机生成；真值深度、实例掩码和物体位姿另存，仅供评价和复原仿真场景。

七种双目方法共得到 504 份点云；固定 GraspGen 比较感知方法、固定 FoundationStereo 比较五种抓取模型，共有 11 条不同组合及 792 个候选／路径任务。三个环境为 FANUC＋Isaac Sim、Franka＋Isaac Sim 和 Franka＋MuJoCo。未产生计划的任务保留在成功率分母中；通过规划的任务在两种材料条件下共有 1244 次完整机械臂物理执行。当前设计与指标定义见 `../latex/outline.tex`。

## 冻结与复跑

模型不训练或微调，场景生成 seed 为 20261011。原文件中的 `development` 等字段是历史批次标签，保留以维持来源与哈希；当前研究范围由 72 场景清单明确给出。

当前分析复用已保存的同一批点云、候选和物理记录，成功与失败均保留。研究问题在观察部分结果后修订，按探索性研究报告；新增方法或参数调整应保留独立版本，不覆盖本批次结果。

历史生成器仍在 `scripts/build_industrial_dataset.py`，其默认配置生成更大的资产库；本次无需重新生成。复用现有数据时必须按 `active_dataset_72.json` 选择场景，不将资产库中的其他场景自动纳入统计。原始文件及历史清单保持不变。

本版只改变平面位置和偏航角；全部工件按解析平面支承摆放，未做动力学落料、随机堆叠、任意滚转俯仰。金属外观采用简化偏哑光材质，尚未验证真实反射、透明物体或相机噪声，不能据此声称解决镜面金属抓取。后续扩展必须另增数据版本。
